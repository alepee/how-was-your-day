# How Was Your Day v0.8.0: Summaries by your coding agent

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.8.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.8.0)

Summaries can now be written by your own coding agent, with the context it already has about you ([#3](https://github.com/alepee/how-was-your-day/pull/3)).

## 🎯 Highlights

- **Agent (ACP) provider**: Claude Code, Codex, Mistral Vibe, Grok, Gemini CLI or any ACP agent
- **Context section**: what the agent knows about people and projects, kept apart and sourced
- **Read-only agent**: HWYD refuses edits, deletions and commands
- **Model lists** for hosted providers

## ✨ What's New

### Agent (ACP) provider

HWYD starts an agent that speaks the Agent Client Protocol (Claude Code through `claude-agent-acp`, Codex through `codex-acp`, Mistral Vibe through `vibe-acp`, Grok through `grok agent stdio`, Gemini CLI through `gemini --experimental-acp`, or any other ACP command), in the working directory you choose.

### Context from the agent

The agent receives the session title, transcript passages and voice names, and is asked to consult its own context read-only (instructions, memory, notes) to place people and projects. What it brings goes into a separate **Contexte** section with its sources; the rest of the summary reports only what was said.

### Submission and permissions

The agent hands the summary back through one MCP tool, `submit_summary`, served by `hwyd-mcp` for that session only. Submissions get the same checks as other providers; a rejected submission returns the reason so the agent can correct it. HWYD allows reading and searching, and refuses editing, deleting, moving, running commands and switching modes. Permissions already granted in the agent's own configuration do not go through HWYD.

### Hosted providers

After saving an API key, the settings list the provider's models, as a menu and as completions. The key is checked first; a rejected key is not stored. The separate "send transcripts" switch is gone: choosing a hosted provider and saving its key is the opt-in. A stage is retried once when the model's output fails validation, and errors name the rule that failed.

### Meeting reminders

Reminders and the upcoming meetings list offer "Rejoindre et enregistrer" (opens the video link and records) and "Enregistrer" without joining.

## 🚧 Known limits

- Agent summaries need the agent installed and signed in, take about one to three minutes and use your agent subscription.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with an `Apple Development` identity but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
