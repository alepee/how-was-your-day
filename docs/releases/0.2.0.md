# How Was Your Day v0.2.0: Voice memory

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.2.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.2.0)

Voice memory is available directly from the speaker editor: name a speaker once, and later transcripts suggest the name.

## ✨ What's New

### Name and remember a voice

Choose **Nommer et mémoriser** to name a speaker and save a local voice fingerprint, or **Nommer seulement** to edit the transcript alone.

### Name suggestions

New diarized transcripts look for remembered voices and show name suggestions to confirm.

### Enrollment and voice panel

Microphone enrollment uses echo-reduced audio. Close microphone, room and remote-call examples stay separate. The voice panel shows enrolled channels and lets you forget a person.

Includes the responsiveness improvements and persistent waveform cache from 0.1.1.

## 🚧 Known limits

- Voice recognition is experimental and needs at least 20 seconds of clean speech.
- Fingerprints stay in the local macOS keychain.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with a persistent self-signed certificate but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
