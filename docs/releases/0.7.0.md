# How Was Your Day v0.7.0: Hosted summary providers

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.7.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.7.0)

Summaries can now run on a hosted model, in addition to a local server ([#2](https://github.com/alepee/how-was-your-day/pull/2)).

## ✨ What's New

### Choose the summary provider

Local server (LM Studio, Ollama), Mistral, OpenAI, Anthropic or Google Gemini, in the settings.

### Your own API key, nothing sent by default

Hosted providers use your own API key, stored in the macOS keychain on this Mac only. Keys never appear in preferences, exports, the database or summary provenance. Nothing is sent until you enable "Envoyer les transcripts à …" for that provider. Each summary then sends the session title, transcript passages and voice names; notes, audio and voice fingerprints are never sent.

### Larger requests

Hosted models read up to 200,000 characters per request instead of 24,000, so a typical one-hour session is summarized in two requests. Local servers keep the previous bounded budget.

### Provider errors

Rejected keys, quotas and unsupported schemas are shown with the provider's own message.

## 🚧 Known limits

- Hosted requests reuse the local prompts and schema; array size limits are applied to the response because hosted engines do not all accept them.
- Structured-output support varies by model. These providers were checked against their request formats, not benchmarked for summary quality.
- Costs are billed to your provider account.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with an `Apple Development` identity but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
