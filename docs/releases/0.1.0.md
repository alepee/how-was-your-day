# How Was Your Day v0.1.0: First experimental release

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.1.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.1.0)

First experimental release of How Was Your Day, a native macOS app that records, transcribes and reviews conversations locally, for Apple Silicon and macOS 26 or later.

## 🎯 Highlights

- **Two-track recording**: microphone and system audio recorded separately, with synchronized playback
- **Local transcription**: French speech recognition on the Mac, with optional speaker diarization
- **Local summaries**: optional, through a local LLM server
- **Agent access**: Markdown/JSON exports and a standalone MCP server

## ✨ What's New

### Recording and playback

Microphone and system audio are recorded on separate tracks. Playback is synchronized, with waveforms, solo and mute per track.

### Transcription and speakers

Transcription runs locally in French. Speaker diarization is optional. Notes and speaker corrections are editable.

### Summaries

Optional local summaries with topic details and timestamp references. A local LLM server is required.

### Calendar, appearance, exports and MCP

Calendar reminders, light and dark appearance, Markdown and JSON exports, and a standalone MCP server for coding agents.

## 🚧 Known limits

- No automatic echo rejection and no audio purge.
- Voice matching is experimental.
- Speech recognition is fixed to French.
- Summary accuracy depends on the model. No embedded LLM or remote API provider yet.

## 📦 Installation

```sh
brew install --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with a persistent self-signed certificate but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
