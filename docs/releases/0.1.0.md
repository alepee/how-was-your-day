First experimental release of How Was Your Day for Apple Silicon and macOS 26+.

- Separate microphone and system audio recording, synchronized playback, waveforms, solo and mute.
- Local French transcription, optional speaker diarization, editable notes and speaker corrections.
- Optional local summaries with topic details and timestamp references.
- Calendar reminders, light/dark appearance, Markdown/JSON exports and a standalone MCP server.

Install with `brew install --cask alepee/tap/how-was-your-day`.

This build is signed with a persistent local certificate but is not notarized by Apple. On first launch, use System Settings > Privacy & Security > Open Anyway if macOS blocks it.

Known limitations: no automatic echo rejection or audio purge, experimental voice matching, fixed French ASR and model-dependent summary accuracy. A local LLM server is required for summaries. No embedded LLM or remote API integration yet.
