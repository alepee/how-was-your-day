# How Was Your Day v0.11.0: English interface, multilingual transcription and a global shortcut

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.11.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.11.0)

The interface speaks English, transcription follows the language spoken, and a global shortcut starts a recording from anywhere ([#8](https://github.com/alepee/how-was-your-day/pull/8), [#10](https://github.com/alepee/how-was-your-day/pull/10)). This is also the first release signed with a Developer ID certificate and notarized by Apple ([#9](https://github.com/alepee/how-was-your-day/pull/9)).

## 🎯 Highlights

- **French and English interface**, following the macOS language
- **Per-track language detection** among the installed Apple Speech languages
- **Global shortcut** to start or end a recording (⌃⌥⌘R)
- **Notarized**: macOS opens the app without the Privacy & Security override

## ✨ What's New

### Interface in French and English

The interface follows the macOS language order: English when English comes before French, French otherwise. A per-app language set in System Settings › General › Language & Region also works. Demo content, stored default voice labels ("Voix 1", "Voix à nommer"), exports and summaries stay in French. See [localization](https://github.com/alepee/how-was-your-day/blob/main/docs/localization.md).

### Transcription follows the language spoken

Each track (microphone and system) gets its own language, detected from its first 90 seconds of audio among the Apple Speech languages installed for HWYD. When detection is not conclusive, HWYD uses the first preferred system language that is installed, otherwise French. The setup screen can force one language for a session, and a transcribed session can be reprocessed with automatic detection or in another installed language (**Transcribe Again**).

### Missing languages

When a track seems to be in a language that is not installed, a notification offers **Install and Transcribe Again** or **Choose the language**. Settings › Audio & Voice lists the installed languages and installs others (**Add a language**). Only Apple SpeechTranscriber is used; each language is about 350 MB, downloaded once. Audio is not sent anywhere for transcription. The former default language setting is gone.

### Language in transcripts and exports

The transcript header shows the language, per track when they differ. Exports add `track_locales` (one locale per track); `locale` stays the microphone's. `hwyd-pipeline languages` prints the installed and supported speech locales as JSON.

### Global shortcut

Start or end a recording with ⌃⌥⌘R while another application is in front. It uses the last session type and automatic language detection, and leaves the window where it is. Change or remove it in Settings › General. It needs no Accessibility permission; HWYD warns when another application already uses the combination.

## 🐛 Bug Fixes

### Language detection details ([#12](https://github.com/alepee/how-was-your-day/pull/12))

Retrying a failed transcription keeps the requested language. Chinese and Cantonese are recognized by detection. Languages are named in the interface language.

## ⚠️ Upgrade note

Because the signer changes, macOS treats the app as new: microphone, system audio and calendar access may need to be granted again, and the keychain may ask once more for access to stored API keys and voice prints. Check that the installed languages are still listed in Settings › Audio & Voice, and add them again if needed (Apple Speech reserves models per application).

## 🚧 Known limits

- Detection reads only the start of each track. A language change later in the session is not followed.
- Code-switching inside a track or a sentence is not handled: a track is transcribed in one language.
- Portuguese may be suggested as Spanish (the message names both).
- Korean speech produces no text with French or English models and is treated like silence.
- Summaries are still written in French, whatever the transcript language.
- The global shortcut has not yet been exercised from another application during a real session.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later; signed and notarized).

Grant permissions again when macOS asks, and check the installed languages (see Upgrade note). Sessions recorded before 0.11.0 have no stored language and stay French; reprocess one to detect its language or choose another. French is the only language installed by earlier versions.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
