# How Was Your Day v0.5.0: Faster voice review, pause and session links

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.5.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.5.0)

Voice review is faster, recordings can be paused, and every recording has a stable link.

## 🎯 Highlights

- **Voice tiles**: play, name and merge voices in place
- **Ignore a voice**, typically a speaker echo
- **Pause and resume** a recording (⌘⇧P)
- **`hwyd://` links** to open a recording

## ✨ What's New

### Voice tiles

Play only one voice's passages, name it once for the whole recording, and drag one voice onto another to merge duplicates.

### Ignore a voice

Ignore a voice, typically an echo of your speakers picked up by the microphone. Its passages are hidden from the transcript, exports, MCP results and summaries. The voice can be restored.

### Playback follows the transcript

The active line is highlighted and scrolls into view during playback.

### Pause and resume

Pause and resume a recording without ending it (⌘⇧P). Nothing is recorded while paused.

### Session links

Open a recording from a `hwyd://session/<id>` link. MCP metadata exposes this link as `source`.

## 🐛 Bug Fixes

### Missing summaries

Exports and MCP no longer promise a summary that was not generated.

## ⚠️ Upgrade note

This release is signed with an `Apple Development` identity instead of the previous self-signed certificate. macOS asks once again for microphone, audio capture and keychain access after the update.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with an `Apple Development` identity but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

Grant microphone, audio capture and keychain access again when macOS asks.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
