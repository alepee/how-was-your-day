# How Was Your Day v0.12.0: A summary made for reading

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.12.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.12.0)

The summary tab is laid out for reading instead of a block of text: you see the overview first, jump straight to decisions and next steps, and open the passages behind each point in one click ([#16](https://github.com/alepee/how-was-your-day/pull/16)).

## 🎯 Highlights

- **Reading layout**: a column of bounded width, the overview first, then counters that jump to each section
- **Decisions and next steps at a glance**: decisions set apart, one row per action with its owner and due date
- **Compact sources**: one button per item to hear the passages it comes from
- **Collapsible topics** and an **outline** on wide windows to move through long meetings

## ✨ What's New

### Reading layout

Text sits in a column of bounded width. The overview comes first, followed by counters for decisions, next steps, topics and context notes; each counter jumps to its section. Key points appear as cards.

### Decisions and next steps

Decisions are set apart with an accent bar. Each next step is one row with the person responsible (initials, shown when the summary names someone), the action and the due date.

### Source references

Each item has a single compact button showing the first passage time and how many others follow (`▸ 29:13 +2`). Hovering lists every passage; clicking moves playback to the first one.

### Collapsible topics and outline

Topics in Details can be collapsed: a collapsed topic shows its title, first sentence and time span. With more than three topics they start collapsed; **Expand all** opens them. On wide windows, an outline next to the column lists sections and topics, highlights the one on screen and jumps to it.

### Context section

Context notes written by a coding agent (Agent (ACP) provider) now have their own collapsible **Context** section, with their sources. A help button explains that they do not come from the conversation.

## 🚧 Known limits

- The outline appears only when the summary area is at least 942 pt wide.
- Summaries are still written in French, whatever the transcript language.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later; signed and notarized).

No summary needs to be generated again. Very old summaries stored as plain Markdown still display as text, without collapsible topics or source buttons; generate them again to get the new layout.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
