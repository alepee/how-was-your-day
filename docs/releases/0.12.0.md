# 0.12.0

The summary tab is laid out for reading instead of a block of text.

- Text sits in a column of bounded width. The overview comes first, followed by counters for decisions, next steps, topics and context notes; each counter jumps to its section. Key points appear as cards.
- Decisions are set apart with an accent bar. Each next step is one row with the person responsible (initials, shown when the summary names someone), the action and the due date.
- Source references are a single compact button per item showing the first passage time and how many others follow (`▸ 29:13 +2`). Hovering lists every passage; clicking moves playback to the first one.
- Topics in Details can be collapsed. A collapsed topic shows its title, first sentence and time span. With more than three topics they start collapsed; **Expand all** opens them.
- Context notes written by a coding agent are now shown in their own Context section, collapsible, with their sources. A help button explains that they do not come from the conversation.
- On wide windows, an outline next to the column lists sections and topics, highlights the one on screen and jumps to it.

## Upgrade notes

- No summary needs to be generated again. Very old summaries stored as plain Markdown still display as text, without collapsible topics or source buttons; generate them again to get the new layout.

## Known limits

- The outline appears only when the summary area is at least 942 pt wide.
- Summaries are still written in French, whatever the transcript language.
