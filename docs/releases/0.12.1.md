# How Was Your Day v0.12.1: Audio interfaces with outputs

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.12.1/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.12.1)

Recording starts with audio interfaces that also have outputs ([#17](https://github.com/alepee/how-was-your-day/pull/17)).

## 🐛 Bug Fixes

### "Unexpected track order" with some audio interfaces

With some interfaces, such as the Native Instruments Komplete Audio 6 (6 inputs, 6 outputs), starting a recording failed with "Unexpected track order: starting channels 1, 13, expected 1, 7". macOS can leave a gap in channel numbers between the microphone and system audio. The check now requires only that the microphone comes before system audio, which is what the capture relies on. Channel counts, sample format and sample rate are still verified before recording starts.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later; signed and notarized).

No migration needed.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
