# 0.12.1

Recording starts with audio interfaces that also have outputs.

- With some interfaces, such as the Native Instruments Komplete Audio 6 (6 inputs, 6 outputs), starting a recording failed with "Unexpected track order: starting channels 1, 13, expected 1, 7". macOS can leave a gap in channel numbers between the microphone and system audio. The check now requires only that the microphone comes before system audio, which is what the capture relies on. Channel counts, sample format and sample rate are still verified before recording starts.
