# How Was Your Day v0.3.0: Echo handling, MCP transcripts and grounded summaries

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.3.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.3.0)

This release improves speakerphone echo handling, transcript access through MCP and the local summary workflow.

## 🎯 Highlights

- **Less residual echo** before transcription, and markers on likely echo
- **Structured MCP reads** with segment-preserving pages and filters
- **Grounded summaries**: topics are mapped before writing from the original transcript

## ✨ What's New

### Echo suppression and markers

Stronger offline residual echo suppression before transcription. An isolated eight-minute comparison reduced repeated transcript words from 122 to 68 (not a WER measurement). Conservative "possible echo" markers flag long microphone fragments that match nearby system speech; they do not delete text or change speaker identity.

### MCP transcripts

Transcript pages preserve segment boundaries, default to 30,000 characters and expose volume totals. Structured reads filter by time, track, speaker and attribution/echo. Tool descriptions and missing-summary reasons are explicit.

### Summary workflow

Summaries map topics before writing from the original transcript. Completed steps are cached locally for recovery. The app shows stage progress and offers a context setting matching the loaded local model.

## 🚧 Known limits

- Residual echo remains possible.
- Small local models remain experimental: valid JSON and faster execution do not establish complete coverage or faithful attribution.
- Remote API generation is not part of the app.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with a persistent self-signed certificate but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

Reconnect MCP clients to load the new tools. Existing transcripts need reprocessing to receive the echo markers and the updated audio treatment. Original audio and existing transcript corrections are preserved unless you explicitly reprocess a session.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
