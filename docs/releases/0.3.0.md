This release improves speakerphone echo handling, transcript access through MCP and the local summary workflow.

- Stronger offline residual echo suppression before transcription. An isolated eight-minute comparison reduced repeated transcript words from 122 to 68. This is not a WER measurement; residual echo remains possible.
- Conservative “possible echo” markers for long microphone fragments matching nearby system speech. Markers do not delete text or change speaker identity. Existing transcripts require reprocessing to receive these markers and the updated audio treatment.
- MCP transcript pages preserve segment boundaries, default to 30,000 characters and expose volume totals. Structured reads support time, track, speaker and attribution/echo filters. Tool descriptions and missing-summary reasons are explicit.
- Summaries now map topics before writing from the original transcript. Completed steps are cached locally for recovery. The app shows stage progress and offers a context setting matching the loaded local model.

Small local models remain experimental: valid JSON and faster execution do not establish complete coverage or faithful attribution. Claude-through-MCP reference work stays separate from the local provider; remote API generation is not added to the app.

Update with `brew update && brew upgrade --cask alepee/tap/how-was-your-day`. Reconnect MCP clients to load the new tools. Original audio and existing transcript corrections are preserved unless you explicitly reprocess a session.
