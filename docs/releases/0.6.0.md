# How Was Your Day v0.6.0: A quieter Studio interface

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.6.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.6.0)

A quieter Studio interface. The layout, the palette and every feature stay; the screens say less and stay consistent ([#1](https://github.com/alepee/how-was-your-day/pull/1)).

## ✨ What's New

### One name, one icon

Start a session under one name and one icon everywhere: "Nouvelle session" in the sidebar, the library and the menu bar. The sidebar entry becomes the running session during a capture, which no longer appears twice. Voice memos and free sessions no longer reuse the app logo and the recording symbol.

### Compact player

The player is half as tall: thinner tracks, no title, no separate position slider. With the player focused, the left and right arrows move playback by 5 seconds, and the position is adjustable by assistive technologies.

### Less text on screen

Voice tiles show on every tab of a session, with their instructions behind a help button. "Corriger ce passage" on every transcript line is replaced by one menu button at the end of the line. The tagline, the local-storage card and the footnotes are gone from the library, the capture screen and the transcript; explanations that matter moved to tooltips and help buttons. The discovery mode is announced once per screen. The interface uses four text sizes.

### Settings

One setting per line, changes apply immediately, no save buttons. Models show whether they are installed. Remembered people are managed under "Audio et voix". "Données locales" and "Agents et exports" are merged. The audio retention preference, which never deleted anything, is hidden (its stored value is kept).

### Voice naming

The example voice "Speaker 3" is renamed "Voix 3", as the pipeline names voices.

## 🚧 Known limits

- The "installed" state of a model is inferred from an installation done in this version or from an existing transcript; a model installed earlier and never used shows "Installer" until then.
- Audio retention is still not enforced.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with an `Apple Development` identity but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
