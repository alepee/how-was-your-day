# How Was Your Day v0.10.0: Bluetooth headset microphones

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.10.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.10.0)

Recording works with a Bluetooth headset microphone ([#7](https://github.com/alepee/how-was-your-day/pull/7)).

## ✨ What's New

### Two aligned clocks

A Bluetooth headset used as microphone switches to call mode and runs at 16 or 24 kHz, while system audio stays at 48 kHz. Recording used to refuse to start (« Fréquences différentes »). Microphone and system audio now run on two separate device clocks: HWYD aligns both tracks on host time and compensates their drift, one sample at a time, beyond 2 ms. With matching rates (built-in microphone, USB interfaces), capture is unchanged.

### Buffer loss diagnostics

When buffers are lost, the error gives the cause counters.

## 🚧 Known limits

- Drift correction is validated on synthetic audio (1000 ppm, alignment within 3 ms) and on short real sessions with a Bluetooth headset. Long-session drift on real devices has not been measured yet.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with an `Apple Development` identity but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
