This update fixes long-transcript responsiveness and adds offline echo cancellation.

- Render transcript rows lazily and reuse unchanged rows during playback.
- Keep speaker-name typing local to the editor instead of refreshing the whole window for every character.
- Poll recording revisions without repeatedly decoding unchanged transcripts.
- Cache waveforms in memory and on disk, with invalidation when audio files change.
- Reduce speakerphone echo before transcription and diarization while keeping original audio intact.
- Keep calendar reminders active after opening or recording an event.

Update with `brew update && brew upgrade --cask alepee/tap/how-was-your-day`.

Echo cancellation is experimental and may leave residual fragments. Retranscribe existing sessions to apply it. This release remains locally signed and not notarized by Apple.
