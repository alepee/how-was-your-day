# How Was Your Day v0.1.1: Responsive transcripts and echo cancellation

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.1.1/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.1.1)

Long transcripts stay responsive, and speakerphone echo is reduced before transcription.

## ✨ What's New

### Offline echo cancellation

Speakerphone echo is reduced before transcription and diarization. The original audio is kept intact.

### Product page

How Was Your Day has a [product page](https://alepee.github.io/how-was-your-day/) on GitHub Pages.

## 🐛 Bug Fixes

### Long transcripts are responsive

Transcript rows render lazily and unchanged rows are reused during playback. Typing a speaker name no longer refreshes the whole window for every character. Recording revisions are polled without decoding unchanged transcripts again. Waveforms are cached in memory and on disk, and invalidated when audio files change.

### Calendar reminders

Calendar reminders stay active after opening or recording an event.

## 🚧 Known limits

- Echo cancellation is experimental and may leave residual fragments.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with a persistent self-signed certificate but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

Retranscribe existing sessions to apply echo cancellation.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
