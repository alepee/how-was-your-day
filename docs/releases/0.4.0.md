# 0.4.0

Local summaries now use bounded requests instead of expanding each request with the meeting's duration. Short transcripts that fit one writing request use two calls. Longer transcripts are organized by topic and written from their original passages, with commitment checks before drafting.

- Give the model an explicit JSON contract as well as the constrained schema.
- Add an optional setting to disable extended reasoning for compatible local servers.
- Prevent HWYD audio model jobs and summary generation from running concurrently.
- Preserve resumable checkpoints and reject oversized indivisible inputs rather than truncating them.
- Add French, English and mixed-language synthetic cases, plus a benchmark harness that measures the inference server's memory separately from the app.
- Save pending edits before taking the summary snapshot, handle cancellation cleanly, and show progress without a premature 100% indicator.

Summaries remain drafts that need review. The [nine synthetic model trials](https://github.com/alepee/how-was-your-day/blob/main/docs/summary-benchmark-results.md) found fidelity errors in every tested configuration, so this release does not select a new default model. Bounded requests do not cap the external server's model weights, buffers or cache. French remains the summary output language. Embedded inference and remote API providers are not included in this release.
