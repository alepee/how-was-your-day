# How Was Your Day v0.4.0: Bounded local summaries

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.4.0/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.4.0)

Local summaries now use bounded requests instead of growing with the meeting's duration. Short transcripts that fit one writing request use two calls; longer ones are organized by topic and written from their original passages, with commitment checks before drafting.

## ✨ What's New

### Bounded requests

The model gets an explicit JSON contract as well as the constrained schema. Oversized indivisible inputs are rejected rather than truncated, and checkpoints stay resumable.

### Reasoning control and job serialization

An optional setting disables extended reasoning on compatible local servers. HWYD audio model jobs and summary generation no longer run concurrently.

### Benchmark cases

French, English and mixed-language synthetic cases, plus a benchmark harness that measures the inference server's memory separately from the app.

## 🐛 Bug Fixes

### Summary lifecycle

Pending edits are saved before the summary snapshot, cancellation is handled cleanly, and progress no longer shows a premature 100%. Verification steps are validated before being cached, and retried once when invalid.

## 🚧 Known limits

- Summaries remain drafts that need review. The [nine synthetic model trials](https://github.com/alepee/how-was-your-day/blob/main/docs/summary-benchmark-results.md) found fidelity errors in every tested configuration, so this release does not select a new default model.
- Bounded requests do not cap the external server's model weights, buffers or cache.
- Summaries are written in French. No embedded inference or remote API provider.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with a persistent self-signed certificate but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

## 🐛 Bug Reports

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
