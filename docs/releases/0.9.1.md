# How Was Your Day v0.9.1: Clearer audio layout errors

[![Downloads for this release](https://img.shields.io/github/downloads/alepee/how-was-your-day/v0.9.1/total.svg)](https://github.com/alepee/how-was-your-day/releases/v0.9.1)

Clearer error when a recording cannot start because of the audio layout ([#6](https://github.com/alepee/how-was-your-day/pull/6)).

## 🐛 Bug Fixes

### Audio layout errors name the failed check

The message « Le format ou l’ordre des pistes n’est pas pris en charge » is replaced by the exact check that failed and the values read: channel count, stream order, sample format, or sample rates of the microphone and system audio. A sample rate mismatch also suggests choosing another microphone or aligning the rates in Audio MIDI Setup.

Recording behaviour is unchanged: a layout the capture pipeline cannot handle still stops before anything is recorded.

## 📦 Installation

```sh
brew update && brew upgrade --cask alepee/tap/how-was-your-day
```

Or download `HowWasYourDay.dmg` below (Apple Silicon, macOS 26 or later).

This build is signed with an `Apple Development` identity but is not notarized by Apple. On first launch, if macOS blocks it, use System Settings › Privacy & Security › **Open Anyway**.

If you encounter issues, please [open an issue](https://github.com/alepee/how-was-your-day/issues/new/choose) with:
- HWYD and macOS versions
- Your audio setup (built-in microphone, USB interface, Bluetooth headset) when recording is involved
- The exact error message

Do not attach recordings, transcripts or summaries of real conversations.
